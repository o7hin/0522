# 🍳 AI 智慧語音互動食譜與創意調酒系統

## 一、專題動機

現代人面對繁忙生活，常苦惱於每天要煮什麼、買什麼，或如何控制預算與熱量。本專題希望結合語音輸入、AI 智能分析與 Arduino 硬體互動，打造一個「懂你、陪你、給你靈感」的食譜與創意調酒建議系統，讓料理與生活變得更簡單、更好玩！

## 二、目標使用者

* 對料理有興趣但不想思考菜單的一般人
* 忙碌又希望控制飲食預算/熱量的上班族或學生
* 喜歡自製創意調酒的年輕人
* 希望透過語音快速互動並獲得個人化建議的使用者

## 三、使用情境描述

* 使用者透過語音告訴系統：
  * 自己現有的食材
  * 今日可用預算
  * 希望總熱量上限
* 按下對應食譜難度（紅/藍/綠）與確認鍵
* OLED 顯示最合適的食譜（名稱、食材、作法、熱量等）
* 額外按鈕可顯示隨機創意調酒建議（含比例與作法）
* 所有建議都會考量使用者過往偏好、自動學習分析，不需手動設定依據

## 四、系統架構（含自動分析）

| 層級 | 元件/技術 | 功能說明 |
|------|----------|----------|
| 使用者 | - | 語音輸入條件、選擇食譜難度與調酒建議 |
| 前端輸入 | 語音辨識 + JS分析 | 處理語音轉文字、萃取食材/預算/熱量等資料 |
| AI核心分析 | Gemini API + JS統計邏輯 | 主動分析偏好食材、預算範圍、風格傾向、自動給建議 |
| 硬體裝置 | Arduino + OLED + 按鈕 | 顯示結果、接收操作（難度鍵、確認鍵、顯示調酒） |
| 調酒邏輯 | JS 隨機生成（2~4材料） | 以便利商店材料+酒類生成創意調酒建議（非制式資料庫） |

## 五、AI分析功能說明（主動智慧）

| 分析項目 | 說明 |
|---------|------|
| 偏好食材分析 | 自動統計近幾次最常輸入的食材，優先推薦包含這些食材的食譜 |
| 預算與熱量預測 | 根據歷史輸入的金額與熱量，自動推測合理建議範圍 |
| 食譜難度偏好 | 根據你最多選擇的難度鍵（紅/藍/綠）預測你偏好挑戰程度 |
| 調酒風格學習 | 依據你使用的材料來源，自動歸類為便利商店風、水果風、經典風等，並隨機生成創意調酒 |

## 六、操作流程

1. 語音輸入食材、預算或熱量（可以混合講）
2. 按下紅/藍/綠鍵選擇食譜難度
3. 按下確認鍵，OLED 顯示對應建議食譜
4. 若想查看調酒建議，按下調酒鍵
5. 調酒建議隨機生成，符合你的風格偏好
6. 所有操作過程中，AI 持續學習並優化建議品質

## 七、技術與材料

### 軟體

* 語音處理：Google Speech-to-Text API
* AI分析：Gemini API（文字生成與理解）
* 資料分析：JavaScript 統計模組（偏好、平均、歸類）
* 硬體介接：Web Serial API

### 硬體

* Arduino（Uno/Nano等）
* OLED 螢幕（顯示食譜與調酒）
* 4 個按鍵（紅/藍/綠/確認 + 調酒）
* USB 傳輸線

## 八、設計亮點

* 🧠 **AI主動分析**：不需手動輸入依據，AI 自動理解你的喜好與需求
* 🎙 **語音互動**：免鍵盤，直覺式語音操作體驗
* 🍸 **創意調酒建議**：不靠資料庫，隨機生成符合個人口味的特調
* 💡 **OLED食譜顯示**：小螢幕大智慧，清楚呈現每道建議
* 🤖 **Arduino互動裝置**：強化實體操作與人機互動感

## 九、預期成果

* 開發一套無需 App、結合語音、AI 分析與實體互動的智慧食譜系統
* 實現 AI 自動學習與偏好預測，提升推薦品質與個人化
* 打造創意調酒功能，拓展食譜推薦的趣味性與延伸應用
* 展現 AI + IoT 在日常生活中具情感與實用性的創新應用場景
